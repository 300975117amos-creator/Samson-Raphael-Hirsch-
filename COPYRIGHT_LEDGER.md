# COPYRIGHT_LEDGER.md

**Rule:** the 19th-century original and any modern translation/annotation are
**separate copyrighted objects.** Publish source text only against an entry here
recording one of: public domain · explicit written permission · compatible open
license · approved limited quotation. Nothing below is cleared for full-text
publication yet. **Review status** is this project's determination.

**Status legend:** 🟢 cleared for stated use · 🟡 likely-but-unverified · 🔴 not
cleared / do not publish · ⛔ blocked pending human/legal decision.

## Working rules

1. A PD **original** never auto-clears a **translation/annotation/introduction**.
2. "Available on archive.org / HathiTrust / Sefaria" ≠ "cleared to republish."
   Confirm the *specific item's* license before any full-text use.
3. Prefer quoting **public-domain originals** (with labeled translation) over
   quoting in-copyright translations.
4. Every image: record creator, date, holder, source link, license, attribution,
   and any modification. No image ships without these.
