# Rabbi Samson Raphael Hirsch — Digital Experience

A source-first digital knowledge and learning platform devoted to Rabbi Samson
Raphael Hirsch (1808–1888), presented as a world-class interactive digital
exhibition. Core concept: **A World Built From Words.**

> **Status: M0 — research foundation & creative direction.** This repository
> currently contains governance, research, and design-system documents plus the
> three proposed creative directions. **No application code exists yet**, and full
> production is intentionally blocked until a human selects a creative direction.

## First principles
Accuracy, transparency, source quality, and copyright compliance take priority over
publishing speed. Every historical claim is traceable to a registered source; every
quotation carries full citation and cleared copyright status. Accessibility
(WCAG 2.2 AA) and reduced motion are designed in. Nothing is invented — including
test, performance, and accessibility results.
