# EDITORIAL_POLICY.md

Governs how historical and interpretive content is researched, written, labeled,
reviewed, and published. Binding on all contributors, human and agent.

## 1. Truth and non-invention

Nothing may be invented: not facts, dates, quotations, citations, page numbers,
titles, editions, translations, relationships, events, interpretations,
permissions, academic consensus, or the availability of a source. If a fact is
not yet verified against a registered source, it is not written as fact — it is
either omitted or explicitly marked **UNVERIFIED** with a research note.

## 2. Claim types — always label

Every non-trivial statement is one of the following, and the page must make the
type unambiguous to a reader:

| Label | Meaning | Evidence required |
|---|---|---|
| **Direct quotation** | Verbatim text from a source | Full citation (§4) + copyright clearance |
| **Paraphrase** | Restatement of a source's content | Source citation |
| **Historical fact** | Verifiable event/date/relationship | ≥1 registered source; ≥2 for contested items |
| **Scholarly interpretation** | A named scholar's reading | Attributed to the scholar + citation |
| **Editorial interpretation** | This project's own reading | Marked as ours; supporting sources listed |
| **AI-assisted summary** | Drafted with model assistance | Marked; every claim independently verified |
| **Unresolved question** | Genuinely open/contested | State the positions and their sources |

## 3. Voice and boundaries

- Never write in the first person as though Rabbi Hirsch is speaking.
- Never fabricate a quotation or "reconstruct" one from memory or paraphrase.
- Never assert what Hirsch "would say" about a modern issue except on a page that
  explicitly frames the passage as **editorial interpretation** and cites the
  primary texts it reasons from.
- Do not issue halachic/religious rulings. Present the site as an educational
  resource, not a substitute for rabbinic or scholarly guidance.
- Prefer neutral, precise, respectful register. Avoid hagiography and avoid
  editorializing about theology.

## 4. Citation standard

Every direct quotation records: **work title · edition · original language ·
translator (if any) · publisher (if available) · publication year · precise
locator** (page / section / chapter / verse / stable digital reference) ·
**copyright status · link or archive reference (if available).** Paraphrases and
facts record at minimum the Source ID from `SOURCE_REGISTRY.md` and a locator.

Original-language quotations should, where possible, appear beside the
translation, with the translation clearly labeled and its translator named.

## 5. Source hierarchy & disagreement

Use the source hierarchy in `PROJECT_BRIEF.md`. Wikipedia and general websites
may surface leads but never settle an important claim. When reliable sources
disagree: (a) record the disagreement in the page and in `RISKS.md`; (b) attribute
each position; (c) explain the uncertainty; (d) never present a contested reading
as settled; (e) request human/expert review when the disagreement is material
(e.g., theological interpretation, contested biography).

## 6. Copyright discipline

See `COPYRIGHT_LEDGER.md`. Original 19th-century text and any modern translation
are separate objects. Publish source text only against a ledger entry recording
public domain, written permission, compatible open license, or approved limited
quotation. Quotation for commentary/criticism is used conservatively and always
attributed; it is never a substitute for clearing a full-text edition.

## 7. Historical page workflow (creator ≠ sole reviewer)

For every important historical page, in order: (1) researcher assembles source
notes → (2) source reviewer verifies source quality → (3) writer drafts →
(4) fact checker checks every claim → (5) citation reviewer verifies references →
(6) copyright reviewer checks quotations/images → (7) editor improves clarity →
(8) Jewish-studies reviewer flags theological/contextual risk → (9) accessibility
reviewer checks structure/language → (10) technical agent publishes →
(11) QA tests → (12) `PROJECT_STATE.md` updated. A page does not publish without
passing this sequence. The creator of a page may not be its only reviewer.

## 8. Corrections

Maintain a public corrections process (page + contact). Log corrections with date
and nature of change; surface revision dates on content pages. Errors are fixed
transparently, not silently.

## 9. Provenance for images

Every archival image records creator (if known), date (if known), holding
institution, original source link, license, required attribution, and any
modification disclosure. Never alter a historical image in a way that implies the
altered version is authentic.
